# Mandi Price Board

Crowd-sourced, tamper-evident crop prices for Indian mandis, built on **Arkiv** (Tiramisu testnet)
for the Arkiv x Devcon 8 pre-Devcon challenge.


## The problem

Small farmers often learn crop prices from the trader who is buying from them. Official data exists
but is slow and hard to use on a phone. A price list that one party can edit or delete cannot be trusted.

## How it works

1. Anyone posts a price report (crop, mandi, price per quintal).
2. Others confirm or dispute it.
3. The board shows the **median of trusted recent reports** per crop and mandi, so one bad report cannot skew it.
4. Reports **expire on their own** after 72 hours, so the board stays fresh.
5. UI in English, Hindi and Marathi.
